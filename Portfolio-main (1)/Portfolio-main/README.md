# Portfolio2

A modern, interactive portfolio website with a sleek dark theme and creative UI/UX designs.

## Features

- Dark theme with cyberpunk-inspired gradient colors
- Responsive design for mobile, tablet, and desktop
- Smooth animations and interactive effects
- Hero, about, education, projects, skills, achievements, and contact sections
- Smooth scrolling, hover effects, ripple buttons, counter animations, and dynamic role text

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome 6.4.0 via CDN

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `script.js` - Interactivity and smooth animations
- `AchImages/` - Achievement images
- `Certificates/` - Certificates

## Deployment

This static site can be deployed with GitHub Pages, Netlify, Vercel, or traditional hosting.
